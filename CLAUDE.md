# CLO-V iOS

SwiftUI app (iOS 17, iPhone only) on Supabase. The Xcode project is generated by XcodeGen from `project.yml`:
add files under `CLOV/Sources/` and run `xcodegen generate`. Never hand-edit `project.pbxproj`.

## Current work: UI redesign

The spec is `docs/ui-redesign-spec.md`. Follow it, in particular:
- Build one phase at a time (spec section 8) and stop after each with: what changed, what was assumed, what to test by hand.
- Database changes are additive only, each with a matching file in `supabase/rollback/`.
- Reuse `Theme`, `FloatingTabBar`, `FlowLayout`, `Haptics` and the other existing components.
- Keep accessibility identifiers, Reduce Motion handling and VoiceOver labels. Update UI tests in the same phase as the UI they cover.
- Do not delete features the sketches omit; relocate them (spec section 2).

## Layout
`CLOV/Sources/{App,Components,Models,Networking,Screens}`; networking is `API.swift` plus `API+<Area>.swift`.
Backend: `supabase/` (see `supabase/migrations/README.md`; run `supabase migration list` before assuming what is applied).
